# Parley's hand-written baseline profile: the code people wait on, compiled ahead of time at install (Play, or the
# profile installer for sideloaded and F-Droid installs) instead of running interpreted until background dexopt.
# Covers start-up to Recents, the keypad, Contacts, a contact's page, and the incoming-call path (call screening, the call screen and its
# notification). `./gradlew :app:generateBaselineProfile` on a device writes a measured profile next to this one
# (src/release/generated/baselineProfiles); both are merged. See docs/PERFORMANCE_BENCHMARKS.md.

# Format: H hot, S startup, P post-startup; `**` matches any classes or members. Names are pre-R8 (AGP maps them).
