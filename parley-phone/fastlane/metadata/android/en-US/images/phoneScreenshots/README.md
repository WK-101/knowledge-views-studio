# Screenshots (D3): to be added

No screenshots are committed yet. Take them on a real device or an emulator and save them here as
`1.png`, `2.png`, ... F-Droid shows them in file-name order, and `1.png` is the first one people see.

- 3 to 8 portrait PNGs (for example 1080 × 2400), light theme, English UI.
- Suggested set: 1 Circle, 2 contact page with its timeline, 3 incoming call, 4 keypad search, 5 Recents,
  6 Blocking, 7 Backup and privacy, 8 Settings search.
- Use demo contacts only, never real names or numbers. Turn on Android's System UI demo mode
  (Developer options) so the status bar shows a fixed clock and no notifications.
- Other languages fall back to these. Add `<locale>/images/phoneScreenshots/` only for translated shots.
- Optional: `images/icon.png` (512 × 512) and `images/featureGraphic.png` (1024 × 500).

F-Droid ignores this file; it only reads image files.
