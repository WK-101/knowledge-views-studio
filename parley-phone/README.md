# Parley Phone (working name)

A privacy-focused, modern **Contacts + Dialer + In-call** app for Android, all in one app. It has no INTERNET permission, no trackers and no accounts.

This project is independent of the rest of this repository.

- [docs/RESEARCH.md](docs/RESEARCH.md): competitor landscape, user demand, platform constraints, architecture decision
- [docs/PLAN.md](docs/PLAN.md): scope, architecture, permissions, milestones, build and release plan
